LARK ANYCROSS

Connect an AnyCross workflow

External setup required · not verified

Use an AnyCross HTTP action to send a message through this workspace's limited Lark API. This does not install or activate a workflow in your Lark account.

  1. Open your AnyCross workspace and create a workflow with an HTTP request action.
  2. Set its method to POST and Content-Type to application/json.
  3. Store the separate LARK_AUTOMATION_TOKEN privately in AnyCross's available credential storage. Select the bearer option for HTTP authentication and supply that token.
  4. Map the JSON body field message to your workflow's intended text (up to 2,000 characters), then run an explicit test.

A successful request sends immediately to the one configured Lark chat. It does not sync the roster or finance records. Check AnyCross availability and HTTP capabilities with your workspace administrator; Lark Pro alone does not guarantee AnyCross access. Treat workflow retries as potential duplicate messages.
